# Screening Task — Specification

## Task

1. Run the app locally and understand the current system.
2. Improve the code in your chosen language folder.
3. Push final code to your private repository.
4. Submit the repository URL via the assignment form.

## Hard Rules

### Provider files

All files in the `providers/` folder simulate external vendor APIs. Treat them as an external service — **do not modify or refactor them**.

### README authorship

README additions must be written **strictly by hand** by the candidate. No coding agents, chat LLMs, or other AI tools may be used to produce README text.

## README Additions

Expand the existing `README.md` with:

- Issues found in the repository
- What you implemented
- Why you chose each approach
- Which AI tools you used and how (for the coding work only)

## AI Tools Policy

Using coding agents or other AI tools for the **coding** part is allowed and expected. Document tool usage in the README — but the README text itself must be written without AI.
